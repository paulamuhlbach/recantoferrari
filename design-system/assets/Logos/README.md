# Logotipo

Arquivos SVG com o texto convertido em curvas (não dependem de fonte instalada).

- `recanto-ferrari-vertical.svg`: versão principal, empilhada, para fundo claro (`surface`). Nome em `ink`, tagline em `accent`.
- `recanto-ferrari-vertical-dark.svg`: a mesma para fundo escuro e azul profundo (`surface-deep`, `blue-1`). Nome em `paper`, tagline CONDOMÍNIO em `primary-container` (terracota clara: 12:1 no `blue-1`, 6:1 no `blue-2`; o `accent` daria só 2,4:1 no `blue-2`). Equivale ao componente `Logo` com `tone="deep"`.
- `recanto-ferrari-horizontal.svg`: casas à esquerda e nome à direita, para cabeçalhos. Fundo claro. Sem tagline.
- `recanto-ferrari-horizontal-dark.svg`: a mesma para fundo escuro e azul profundo. Nome em `paper`, sem tagline.
- `recanto-ferrari-simbolo.svg`: só as três casas. Favicon, avatar e selos. Funciona nos dois fundos.

As cores das casas são fixas: telhados `terracotta-2` / `terracotta-1` (central), base `terracotta-3`.
