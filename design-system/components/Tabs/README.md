# Tabs

Abas para alternar entre visões da mesma página.

**Props:** `items` (`[{ value, label, icon, count }]`), `value`, `onChange`, `label` (nome do grupo para leitores de tela).

- Ex.: Reservas → Próximas · Histórico · Espaços.
- De 2 a 5 abas, rótulos de uma palavra. Em telas estreitas a barra rola na horizontal.
- `count` mostra um número em pílula (itens pendentes).
