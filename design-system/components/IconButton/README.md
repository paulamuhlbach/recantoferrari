# IconButton

Botão redondo só com ícone, para ações compactas em barras e cards.

**Props:** `icon`, `label` (obrigatório: vira `aria-label` e dica), `variant` = `"standard"` | `"filled"` | `"tonal"` | `"outlined"`, `selected`, `disabled`.

- Use quando o ícone é universal: menu, fechar, buscar, notificações.
- Para ações com texto, prefira `Button`.
