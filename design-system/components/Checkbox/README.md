# Checkbox

Caixa de seleção com rótulo e texto de apoio opcional.

**Props:** `label`, `supporting`, `checked`/`defaultChecked`, `onChange`, `disabled`, `name`, `value`.

- Para aceites ("Li e aceito o regulamento") e listas de opções independentes.
- Para ligar e desligar uma preferência que vale na hora, use `Switch`.
